Noções básicas de informática: SOFTWARE

O que é Software?

Software são os programas e sistemas operacionais que fazem a integração entre o usuário e o computador.

Sistema Operacional

Exemplos: Windows, Linux

O sistema operacional é onde os programas e funções estão organizados. Ele serve como base para a execução dos aplicativos.

Atualmente, o Windows é o sistema operacional mais utilizado por ser mais simples para o usuário comum. Já o Linux possui diversas versões gratuitas, oferece grande possibilidade de personalização e é bastante utilizado por desenvolvedores e usuários avançados.

Principais funções:

  • Área de trabalho: tela principal do sistema.
  • Menu Iniciar: acesso a programas e configurações.
  • Barra de tarefas: exibe programas abertos, horário e calendário.
  • Pastas: organizam arquivos.
  • Explorador de Arquivos: localiza documentos, fotos e outros arquivos.

Editor de Texto

Exemplos: Microsoft Word, LibreOffice Writer, Google Docs

Programa utilizado para criar e editar textos. Geralmente já vem configurado para impressão em papel A4, mas permite outros formatos.

Principais recursos:

  • Digitar textos
  • Alterar tamanho e cor da fonte
  • Inserir imagens
  • Salvar documentos
  • Imprimir arquivos

Exemplos de uso:

  • Trabalhos escolares
  • Currículos
  • Cartas e documentos
  • Documentos com ou sem imagens

Editor de Planilhas

Exemplos: Microsoft Excel, LibreOffice Calc, Google Planilhas

Utilizado para organizar informações em tabelas e realizar cálculos.

Principais recursos:

  • Criar tabelas
  • Fazer contas automáticas
  • Organizar dados
  • Criar gráficos
  • Controle de contabilidade

Exemplos de uso:

  • Controle de gastos
  • Lista de presença
  • Planilhas de notas

Navegador de Internet (Browser)

Exemplos: Google Chrome, Mozilla Firefox, Microsoft Edge, Opera

É o programa utilizado para acessar páginas da internet. Na barra de endereço ou pesquisa você pode digitar sites ou pesquisar conteúdos.

Com ele você pode:

  • Pesquisar informações
  • Acessar sites
  • Assistir vídeos
  • Fazer downloads

Noções básicas de informática: HARDWARE

O que é Hardware?

Hardware é a parte física do computador, ou seja, todos os componentes, peças e equipamentos que formam a máquina.

Principais componentes do computador

Processador (CPU)

É considerado o cérebro do computador.

Funções:

  • Executar cálculos
  • Processar informações
  • Controlar tarefas

Memória RAM

Armazena informações temporárias enquanto o computador está em uso.

Funções:

  • Auxiliar na execução dos programas
  • Permitir o uso simultâneo de vários programas

Disco Rígido (HD) ou SSD

Responsável pelo armazenamento permanente dos arquivos.

Exemplos de arquivos armazenados:

  • Fotos
  • Jogos
  • Programas
  • Documentos

Diferença:

  • HD: maior capacidade por menor custo.
  • SSD: maior velocidade de funcionamento.

Placa-mãe

É a peça principal responsável por conectar todos os componentes.

Função:

  • Permitir a comunicação entre as peças.

Fonte de Alimentação

Função:

  • Distribuir energia elétrica para todos os componentes.

Placa de Vídeo (GPU)

Funções:

  • Exibir imagens
  • Executar jogos
  • Trabalhar com vídeos e gráficos

Monitor

Mostra imagens e informações na tela.

Teclado

Permite digitar textos e comandos.

Mouse

Permite mover o cursor e selecionar opções na tela.

Resumo Rápido

  • CPU: pensa e processa informações.
  • RAM: ajuda a executar tarefas.
  • HD/SSD: guarda arquivos.
  • Placa-mãe: conecta todos os componentes.
  • Fonte: fornece energia.
  • Placa de vídeo: gera imagens.
  • Monitor: exibe o conteúdo.
  • Teclado e Mouse: permitem a interação com o computador.
